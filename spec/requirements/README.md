## 要求仕様の位置づけ

要求仕様書は、プロジェクトの「何を作るか」を定義します：

- **ユーザー要件**: 対象ユーザーと利用シーン
- **機能要件**: 各画面・機能の詳細仕様
- **非機能要件**: 性能・セキュリティ・運用要件
- **制約条件**: 技術的・運用的な制約
- **優先度**: 開発順序と重要度
