# 在庫画面 UI仕様書

## 画面概要
食材の在庫・期限管理を行う中核画面。多様な登録方法（手動・バーコード・レシート読み取り）による在庫追加、期限監視システム、自動減算システム、優先消費提案を提供する包括的な在庫管理システム。

## 主要機能
- 多様な在庫登録方法（手動・バーコード・レシート読み取り・買い物リスト連携）
- 段階的期限アラート通知（期限・在庫量を考慮）
- 調理時の使用量自動減算システム
- 期限・在庫量を考慮した優先消費提案
- 余剰在庫活用レシピ自動提案
- 保存場所・温度帯管理

#### 構成要素
- **戻るボタン**: 前画面への遷移

- **バーコードスキャン**: 商品登録・検索
- **買い物リスト**: 不足食材の一括登録

## 詳細インタラクション設計

### 在庫登録フロー（バーコードスキャン）
1. **スキャンボタンタップ**: カメラ画面起動
2. **バーコード読み取り**: 商品情報の自動取得
3. **商品情報確認**: 取得データの確認・補正
4. **詳細入力**: 数量・期限・保存場所の入力
5. **保存**: データベース登録・関連データ更新

### 使用記録フロー
1. **使用ボタンタップ**: 使用量入力ダイアログ表示
2. **数量入力**: スライダーまたは数値入力
3. **用途入力**: 使用目的の任意記録
4. **在庫更新**: 残量の自動計算・更新
5. **履歴記録**: 使用履歴の保存

### 期限アラートフロー
1. **バックグラウンド監視**: 期限日程の定期チェック
2. **アラート発火**: 設定日数前に通知生成
3. **通知表示**: プッシュ通知・アプリ内通知
4. **アクション提示**: レシピ提案・購入提案・廃棄提案
5. **対処実行**: 選択したアクションの実行

## 状態管理

### データ状態
```typescript
interface InventoryScreenState {
  // 在庫データ
  stockItems: StockItem[]
  filteredItems: StockItem[]
  selectedItem: StockItem | null
  
  // フィルター・検索
  searchQuery: string
  activeFilters: InventoryFilters
  sortOrder: 'expiry_date' | 'added_date' | 'usage_frequency' | 'name'
  
  // UI状態
  viewMode: 'list' | 'grid'
  loading: boolean
  error: string | null
  
  // 期限アラート
  expiryAlerts: ExpiryAlert[]
  alertSettings: AlertSettings
  
  // スキャン・入力
  scannerActive: boolean
  scanResult: ProductScanResult | null
  editingItem: StockItem | null
  
  // 使用記録
  usageRecords: UsageRecord[]
  showUsageDialog: boolean
  
  // 統計・分析
  inventoryStats: InventoryStatistics
  wastageStats: WastageStatistics
}
```

## エラーハンドリング

### バーコードスキャンエラー
- **読み取り失敗**: 再スキャン・手動入力への誘導
- **商品情報未登録**: 手動入力フォームの提供
- **カメラ権限エラー**: 設定画面への誘導

### 期限計算エラー
- **不正な日付**: デフォルト期限の提案
- **過去の期限**: 警告表示・確認ダイアログ
- **期限未設定**: 食材別推定期限の提案

## アクセシビリティ対応

### 音声読み上げ
- 在庫情報: "人参、残り150グラム、期限まで3日"
- 期限アラート: "期限切れ食材2件、期限間近4件あります"
- 使用記録: "人参150グラムを使用しました。残り150グラムです"

### 色覚サポート
- 期限状態: 色だけでなくアイコン・パターンでも表現
- 在庫状態: 数値・文字による明確な状態表示
- アラート: 視覚的・聴覚的な多重通知

## パフォーマンス最適化

### データローディング
- **仮想スクロール**: 大量在庫の効率表示
- **段階的ローディング**: 必要な在庫データの優先読み込み
- **キャッシュ戦略**: 頻繁にアクセスされるデータの保持

### 画像処理最適化
- **サムネイル生成**: 食材写真の軽量版作成
- **遅延ローディング**: スクロール時の段階的画像読み込み
- **圧縮処理**: アップロード時の自動圧縮

### バックグラウンド処理
- **期限監視**: 非同期での定期チェック
- **統計計算**: バックグラウンドでの分析処理
- **同期処理**: オフライン時のデータ同期
