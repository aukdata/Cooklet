# コスト画面 UI仕様書

## 画面概要
食費の記録・分析画面。レシート読み取り機能による自動入力、月次・年次での支出推移の可視化、予算管理機能を提供する。

## 主要機能
- レシート撮影による支出記録
- 支出履歴の一覧表示・編集
- 月次・年次の支出分析・グラフ表示
- 予算設定・アラート機能
- カテゴリ別支出分析

## インタラクション設計

### レシート撮影フロー
1. **カメラ起動**: タップでカメラアプリ起動
2. **撮影**: レシートを枠内に配置して撮影
3. **解析処理**: ローディング表示 (3-5秒)
4. **結果確認**: 解析結果の確認・編集
5. **保存**: データベースへ保存・在庫自動更新

### 支出編集フロー
1. **項目選択**: 履歴から編集対象選択
2. **編集モーダル**: 金額・カテゴリ・メモ編集
3. **保存確認**: 変更内容の確認ダイアログ
4. **更新完了**: データ更新・画面リフレッシュ

### グラフ・分析インタラクション
1. **期間変更**: タブ選択で表示期間変更
2. **詳細表示**: グラフ要素タップで詳細情報表示
3. **カテゴリフィルタ**: 凡例タップで表示切り替え

## 状態管理

### データ状態
```typescript
interface CostScreenState {
  // 支出データ
  expenses: Expense[]
  filteredExpenses: Expense[]
  
  // フィルタ状態
  dateRange: DateRange
  selectedCategories: string[]
  selectedStores: string[]
  searchQuery: string
  
  // UI状態
  activeTab: 'record' | 'history' | 'analysis' | 'budget' | 'settings'
  loading: boolean
  error: string | null
  
  // レシート処理状態
  receiptProcessing: boolean
  receiptResult: ReceiptAnalysisResult | null
  
  // 予算データ
  budget: BudgetConfig
  budgetProgress: BudgetProgress
}
```

### アクション
```typescript
// 支出データ操作
- fetchExpenses(filters: FilterOptions)
- addExpense(expense: Expense)
- updateExpense(id: string, expense: Partial<Expense>)
- deleteExpense(id: string)

// レシート処理
- processReceipt(image: File)
- confirmReceiptResult(result: ReceiptAnalysisResult)
- reprocessReceipt(image: File)

// フィルタ・検索
- setDateRange(range: DateRange)
- setCategories(categories: string[])
- setSearchQuery(query: string)

// 予算管理
- setBudget(budget: BudgetConfig)
- updateBudgetProgress()
```

## エラーハンドリング

### レシート処理エラー
- **撮影失敗**: カメラ再起動・ギャラリー選択提案
- **解析失敗**: 手動入力への誘導
- **ネットワークエラー**: オフライン保存・後で同期

### データ同期エラー
- **接続失敗**: ローカル保存・同期マーク
- **認証エラー**: 再ログイン誘導
- **容量不足**: データクリーンアップ提案
