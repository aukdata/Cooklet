# レシピ画面 UI仕様書

## 画面概要
料理レシピの管理・検索・作成を行う画面。写真付きレシピの登録、外部サイトからの自動抽出、詳細検索機能、動的分量調整を提供する高機能レシピ管理システム。

## 主要機能
- レシピ登録（手動入力・外部URL・AI自動抽出）
- 写真付きレシピ作成・編集
- 詳細検索・フィルタリング（材料名・在庫有無）
- 動的分量調整（人数・在庫量対応）
- 外部リンク連携・保存
- レシピ提案（在庫優先・栄養バランス）
- コスト計算・栄養分析

## 詳細インタラクション設計

### レシピ作成フロー
1. **作成方法選択**: 手動・URL・写真・AI生成から選択
2. **データ入力**: 選択した方法に応じた入力画面
3. **自動処理**: URL/写真の場合はAI処理 (5-10秒)
4. **確認・編集**: 抽出結果の確認と手動補正
5. **保存**: データベース保存・画像アップロード

### 人数調整フロー
1. **人数変更**: スライダーまたは数値入力
2. **分量計算**: 全材料の分量を自動再計算
3. **在庫確認**: 調整後分量と在庫の照合
4. **不足材料表示**: 足りない材料のハイライト

### 献立追加フロー
1. **献立追加ボタン**: レシピ詳細から献立への追加
2. **日時選択**: カレンダーから追加日時選択
3. **時間帯選択**: 朝・昼・夕・間食から選択
4. **人数設定**: 作成人数の調整
5. **確定**: 献立カレンダーへの反映

## エラーハンドリング

### URL抽出エラー
- **サイト非対応**: 対応サイト一覧表示・手動入力提案
- **抽出失敗**: 再試行ボタン・手動入力への誘導
- **ネットワークエラー**: オフライン通知・後で再試行

### 画像処理エラー
- **認識失敗**: 再撮影・手動入力提案
- **画像品質低**: 撮影ガイダンス表示
- **容量オーバー**: 画像圧縮・リサイズ提案

## アクセシビリティ対応

### 音声読み上げ
- レシピ情報: "鶏の照り焼き、調理時間30分、難易度中級"
- 材料リスト: "鶏もも肉400グラム、在庫あり"
- 手順読み上げ: "手順1、鶏肉を一口大に切る"

### キーボード操作
- Tab順序: 検索 → フィルター → レシピカード → アクション
- ショートカット:
  - Ctrl+F: 検索フォーカス
  - Space: カード選択・詳細表示
  - Enter: アクション実行

## パフォーマンス最適化

### データローディング
- **仮想スクロール**: 大量レシピの効率表示
- **ページネーション**: 段階的データ読み込み
- **プリフェッチ**: よく閲覧されるレシピの事前読み込み

### 画像最適化
- **サムネイル生成**: 複数サイズの自動生成
- **遅延ローディング**: スクロール時の段階的画像読み込み
- **WebP変換**: 高効率フォーマットでの保存

### 検索最適化
- **インデックス活用**: 全文検索インデックス
- **キャッシュ戦略**: 検索結果の短期キャッシュ
- **デバウンス**: 入力中の不要なAPI呼び出し抑制
