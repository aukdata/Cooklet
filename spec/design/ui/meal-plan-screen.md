# 献立画面 UI仕様書

## 画面概要
週/月単位での食事計画を管理するメイン画面。カレンダー形式で朝昼夕の食事を視覚的に管理し、自動献立生成、買い物リスト作成、栄養バランス分析を提供する。

## 主要機能
- 週/月単位でのカレンダー式献立表示
- 朝・昼・夕・間食の時間帯別献立管理
- レシピ・作り置き・在庫消費・外食の多様な献立アイテム対応
- 自動献立生成（在庫優先・栄養バランス考慮）
- 材料積算計算と買い物リスト自動生成
- 献立履歴管理と再利用機能

## 詳細インタラクション設計

### スロット選択フロー
1. **空スロットタップ**: オプションメニュー表示
2. **選択肢選択**: レシピ選択・作り置き・在庫活用等
3. **詳細設定**: 人数・調理時間・メモ追加
4. **確定**: 献立への登録完了

### 献立編集フロー
1. **登録済スロットタップ**: 献立詳細カード表示
2. **編集ボタンタップ**: 編集モード移行
3. **内容変更**: 人数・レシピ変更・メモ編集
4. **保存**: 変更内容の確定・材料リスト更新

### 自動生成フロー
1. **生成ボタンタップ**: 設定画面表示
2. **条件設定**: 期間・優先度・制約条件設定
3. **生成実行**: AI処理 (3-5秒のローディング)
4. **結果確認**: 提案献立の一覧表示
5. **個別調整**: 気に入らない献立の個別変更
6. **一括適用**: 献立カレンダーへの反映

### コピー・複製フロー
1. **長押し操作**: 対象スロットを長押し
2. **コピーメニュー**: 「他の日にコピー」選択
3. **対象日選択**: カレンダーから貼り付け先選択
4. **時間帯選択**: 朝・昼・夕・間食から選択
5. **確定**: 複製完了

## 状態管理

### データ状態
```typescript
interface MealPlanScreenState {
  // 表示制御
  currentPeriod: DateRange
  viewMode: 'week' | 'month'
  selectedDate: Date
  
  // 献立データ
  mealPlans: MealPlan[]
  availableRecipes: Recipe[]
  madeAheadMeals: MadeAheadMeal[]
  
  // UI状態
  loading: boolean
  selectedSlot: MealSlot | null
  showAutoGenerator: boolean
  showMealOptions: boolean
  
  // 自動生成設定
  generationSettings: GenerationSettings
  generationResult: GeneratedMealPlan[]
  
  // 栄養・コスト分析
  nutritionSummary: NutritionSummary
  costEstimate: CostEstimate
}
```

### アクション
```typescript
// 表示制御
- setViewMode(mode: 'week' | 'month')
- navigatePeriod(direction: 'prev' | 'next')
- selectDate(date: Date)

// 献立操作
- addMealToSlot(slot: MealSlot, meal: Meal)
- updateMeal(mealId: string, updates: Partial<Meal>)
- removeMeal(mealId: string)

// データ連携
- fetchMealPlans(period: DateRange)
- generateShoppingList(period: DateRange)
- calculateNutrition(mealPlans: MealPlan[])
```

## エラーハンドリング

### 自動生成エラー
- **材料不足**: 代替提案・買い物リスト生成提案
- **レシピ不足**: 新規レシピ追加の提案
- **制約条件厳しすぎ**: 設定緩和の提案

### データ同期エラー
- **ネットワークエラー**: ローカル保存・後で同期
- **整合性エラー**: 材料・在庫データとの不整合検出・修正提案

## アクセシビリティ対応

### 音声読み上げ
- 日付の読み上げ: "1月15日月曜日、朝食"
- 献立の読み上げ: "鶏の照り焼き、2人前、調理時間30分"
- 在庫状況: "材料不足2件、在庫確認が必要です"

### キーボード操作
- Tab順序: 日付 → 時間帯 → アクションボタン
- ショートカット: 
  - Space: スロット選択・決定
  - Escape: メニュー・ダイアログ閉じる
  - 矢印キー: カレンダーナビゲーション

## パフォーマンス最適化

### データローディング
- **段階的ローディング**: 表示期間分のみ優先読み込み
- **プリフェッチ**: 前後の週・月のデータ事前取得
- **キャッシュ活用**: 一度読み込んだデータの再利用

### レンダリング最適化
- **仮想化**: 月表示時の大量日付の効率描画
- **メモ化**: 変更のないスロットの再描画回避
- **遅延レンダリング**: 画面外要素の遅延描画

### 画像最適化
- **サムネイル生成**: レシピ画像の軽量版作成
- **遅延ローディング**: スクロール時の段階的画像読み込み
- **キャッシュ戦略**: 頻繁に使用される画像の長期キャッシュ
