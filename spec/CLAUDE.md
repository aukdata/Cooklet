# Cooklet 仕様書

料理管理アプリケーション

## 機能一覧

### ユーザ管理
- ユーザ作成
- パスワード変更
- 通知設定

### 材料管理
- 材料マスター登録
  - 材料名
  - 通常使用単位
  - 調味料フラグ（消費考慮外）
- 文字列変換テーブル
  - レシート文字列から材料への変換ルール
  - 単位・量の変換設定

### レシピ管理
- レシピ登録
  - URLから材料自動抽出
  - 人前情報
  - メモ機能
- レシピ一覧表示
- 献立への追加（日付指定）

### 献立管理
- 日別三食＋その他の献立設定
- 献立構成要素
  - レシピ（人前指定）
  - 素材（単位・量指定）
  - 作り置き（人前指定）

### 作り置き管理
- レシピ紐付け
- 作成日記録
- 残量管理（人前単位）

### 在庫管理
- 現在在庫量
- 材料マスター紐付け
- 数量管理
